## Sobre mim

Sou Analytics Engineer com experiência em engenharia de dados, web analytics e desenvolvimento de software assistido por IA. Desde 2021, atuo em projetos de dados e marketing analytics para empresas de varejo, telecom, fintech e serviços. Curso Ciência de Dados na UNIVESP e participo de iniciação científica no grupo GOMPU. Gosto de transformar dados brutos em produtos de dados confiáveis e de construir fluxos de IA fáceis de testar e manter.

## Projetos selecionados

### StudyFlow — planejador de estudos com IA
Aplicação web que ajuda estudantes a organizar objetivos de estudo. Construída com Google AI Studio (Gemini), React 19, TypeScript, Vite e Tailwind CSS, com deploy serverless no Google Cloud Run.

- Desenvolvimento guiado por especificação (GCCD): Goal, Context, Constraints, Done-when.
- Engenharia de contexto com `AGENTS.md` e `SKILL.md`.
- 10 critérios de aceite validados.

[Repositório](https://github.com/mordonha/StudyFlow---APP)

### BuscaRM — busca de registros de matrícula escolar
Projeto acadêmico em equipe: aplicação web para buscar registros de matrícula escolar com suporte a OCR. Construída com Java 21, Spring Boot, Next.js, PostgreSQL e Tesseract OCR.

- Tempo de busca reduzido de cerca de 15 minutos para menos de 2 segundos.
- Fluxo de importação com validação humana, pré-visualização e confirmação.

[Repositório](https://github.com/mordonha/buscarm)
