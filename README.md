## Selected projects

### StudyFlow — AI-assisted study planner
A web app that helps students organize study goals. Built with Google AI Studio (Gemini), React 19, TypeScript, Vite, and Tailwind CSS, with serverless deployment on Google Cloud Run.

- Spec-driven development with GCCD: Goal, Context, Constraints, Done-when.
- Context engineering with `AGENTS.md` and `SKILL.md`.
- 10 acceptance criteria validated.

[Repository](https://github.com/mordonha/StudyFlow---APP)

### BuscaRM — school enrollment records search
An academic team project: a web app to search school enrollment records with OCR support. Built with Java 21, Spring Boot, Next.js, PostgreSQL, and Tesseract OCR.

- Search time reduced from about 15 minutes to under 2 seconds.
- Human-in-the-loop import flow with validation and preview.

[Repository](https://github.com/mordonha/buscarm)
